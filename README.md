# Warehouse Wreckage

A physics sandbox game built in **Unreal Engine 5** using Blueprints, following the [Unreal Engine 5 C++ Developer course](https://www.udemy.com/course/unrealcourse/) by GameDev.tv / Ben Tristem on Udemy. The first project in the course — focused on getting comfortable with the UE5 editor and Blueprint scripting.

## Tech
- **Unreal Engine 5**
- Blueprints (no C++ in this project)
- Physics simulation

## Gameplay
The player shoots projectiles in a warehouse environment, knocking over crates and barrels using UE5's physics engine.

## How to Open
1. Install Unreal Engine 5 via Epic Games Launcher
2. Open `WarehouseWreckage.uproject`

## What I Learned
- UE5 editor navigation and project structure
- Blueprint visual scripting fundamentals
- Physics actors, impulse forces, and collision setup
- Basic input handling and game mode configuration
